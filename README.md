# 土俵バトル (Sumo Battle) — 1vs1 ジャイロ相撲

スマホを傾けて操作する、1対1の本気相撲ブラウザゲーム。

## あそびかた
1. 2人で同じ**合言葉**を入力 → 「対戦開始」
2. P2P (WebRTC / PeerJS) でマッチング
3. スマホを傾けて力士を操作。**相手を土俵の外へ押し出せば勝ち**
4. 右下の「突進」ボタンでタックル（スタミナ消費）
5. 先に2本取った方が勝者

## 技術
- 通信: PeerJS（公式公開シグナリングサーバ）
- 物理: 自前 2D 衝突 + 反発
- 操作: DeviceOrientation (gyro) + タッチ/キーボードフォールバック
- ホスト権威方式: 合言葉から決定的に host/guest を決める

## ローカル起動
ただの静的ファイルです。
```
python3 -m http.server 8000
```
それから https://<your-host>/ をスマホで開く（HTTPS 推奨。GitHub Pages は HTTPS）。

## デプロイ
`main` ブランチ → GitHub Pages（`/` ルート）。
