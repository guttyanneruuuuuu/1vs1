# 土俵バトル (Sumo Battle) — 1vs1 ジャイロ相撲

スマホを傾けて操作する、1対1の本気相撲ブラウザゲーム。**大幅リニューアル版**

## 🎮 あそびかた

1. 2人で同じ**合言葉**を入力 → 「対戦開始」
2. P2P (WebRTC / PeerJS) でマッチング
3. スマホを傾けて力士を操作。**相手を土俵の外へ押し出せば勝ち**
4. 画面下の3つのアクションボタンで戦略的に戦う：
   - **突進**: 基本的なタックル（スタミナ消費: 35）
   - **スピン**: より強力な回転攻撃（スタミナ消費: 50）
   - **防御**: ダメージを軽減する防御ポーズ（スタミナ消費: 25）
5. 連続ヒットで**コンボ**が発生！
6. 先に2本取った方が勝者

## ✨ 新機能（リニューアル内容）

### 1. スペシャルアクションシステム
- **スピンアタック**: 通常のタックルより強力で、より多くのダメージを与える
- **防御ポーズ**: 相手の攻撃を受けた時にダメージを60%軽減
- 各アクションで異なるスタミナ消費とクールタイム

### 2. スペシャルゲージシステム
- 衝撃を受けるたびにゲージが増加
- ゲージが満タンになると必殺技が発動可能に
- 戦闘中の画面下部に表示

### 3. コンボシステム
- 連続ヒットでコンボカウンターが増加
- コンボ数が画面中央に大きく表示される
- コンボ時に特別な効果音が鳴る
- 1秒以上ヒットがないとリセット

### 4. 画面エフェクト
- **画面シェイク**: 強い衝撃時に画面が揺れる
- **スピンアニメーション**: スピンアタック時に回転エフェクト表示
- **防御シールド**: 防御中に青いシールドが表示される
- より迫力のあるゲーム体験

### 5. CPU AI強化
- 難易度レベル（Easy/Normal/Hard）に対応
- 難易度に応じた戦略変更
- スペシャルアクションも使用

### 6. UI改善
- スペシャルゲージ表示
- コンボカウンター表示
- 複数のアクションボタン配置
- キーボード操作対応（Q=スピン、E=防御）

## 🛠️ 技術

- 通信: PeerJS（公式公開シグナリングサーバ）
- 物理: 自前 2D 衝突 + 反発（ダメージ軽減対応）
- 操作: DeviceOrientation (gyro) + タッチ/キーボードフォールバック
- ホスト権威方式: 合言葉から決定的に host/guest を決める
- エフェクト: Canvas 2D による画面シェイク、パーティクル、アニメーション

## ⌨️ キーボード操作（デスクトップテスト用）

- **矢印キー / WASD**: 移動
- **スペースキー**: 突進
- **Q キー**: スピン
- **E キー**: 防御

## 🚀 ローカル起動

ただの静的ファイルです。

```bash
python3 -m http.server 8000
```

それから `https://<your-host>/` をスマホで開く（HTTPS 推奨。GitHub Pages は HTTPS）。
